# 시뮬레이션 보고서 페이지 리디자인 및 배경색 정렬

## 1. 배경 및 목적

- 시뮬레이션 보고서 화면을 새로운 디자인 샘플(`tmp_report.html`)과 API 응답 예시(`tmp_report.json`) 기준으로 재구성.
- 기존 보고서 페이지를 데이터 구조에 맞게 동적으로 렌더링하고, 이후 다른 시뮬레이션 페이지와 색상 톤을 일치시키는 후속 UI 조정 수행.

## 2. 프롬프트 (User Input)

```text
다음은 시뮬레이션 보고서의 새로운 디자인 샘플과 보고서에서 요청/응답할 json형식 파일이야. 해당 파일들을 바탕으로 보고서 페이지를 새롭게 구성해줘.

배경색을 다른 페이지 색이랑 맞춰줘.

보고서 페이지의 모든 카드들의 배경색도 페이지 배경색과 동일하게 맞춰줘
```

## 3. AI 응답 요약 (AI Output)

- 기존 보고서 페이지(`src/app/simulation/[id]/report/page.tsx`)를 샘플 레이아웃 중심으로 재작성.
- `SimulationReportResponse` 타입에 `aiScore`, `aiComment`를 optional로 확장해 JSON 예시와의 호환성 확보.
- 요약 점수/등급, 에이전트 의견, 거래 상세, 하단 통계 카드 섹션을 API 응답 기반으로 동적 렌더링.
- 후속 요청에 따라 페이지 배경색을 시뮬레이션 메인 페이지 톤(`light: #f6f7f8`, `dark: #101922`)으로 통일.
- 마지막 요청으로 보고서 내 모든 카드의 배경색도 페이지 배경색과 동일하게 맞추고 다크 보더 톤 정렬.

## 4. 결과 및 적용 (Result)

- 실제 반영 파일
  - `src/app/simulation/[id]/report/page.tsx`
  - `src/services/simulationService.ts`
- 타입 에러/문법 에러 확인 결과, 수정 파일 기준 에러 없음.
- 최종적으로 보고서 페이지는 다음을 만족:
  - 디자인 샘플 기반 구조 반영
  - 제공된 JSON 필드 기반 데이터 바인딩
  - 기존 시뮬레이션 페이지와 동일한 배경 톤 유지
  - 카드 배경과 페이지 배경의 완전한 색상 일치

## 5. 기타

- 디자인 시안의 시각적 아이덴티티(강조색, 섹션 구성)는 유지하되, 프로젝트 내 기존 시뮬레이션 페이지 톤과 충돌하지 않도록 배경 및 카드 색상을 통합함.
- 추가 미세 조정 후보: 카드 그림자 강도(`shadow-sm`) 및 hover 보더 대비 축소.
