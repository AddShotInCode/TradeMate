# 시뮬레이션 기능 구현 (Simulation Feature Implementation)

## 1. 배경 및 목적

- **배경**: 기존 시뮬레이션 페이지는 정적인 데이터와 차트만 보여주고 있어, 사용자가 원하는 종목과 시점을 선택하여 연습할 수 없는 문제가 있었습니다. 또한 한국 시장에 맞지 않는 UI 스타일(캔들 색상 등)과 사용성 문제(십자선, 데이터 로딩)가 존재했습니다.
- **목적**: 사용자가 원하는 종목과 날짜를 선택하여 시뮬레이션을 시작할 수 있도록 하고, 한국 주식 시장에 익숙한 UI 경험을 제공하며, 차트 동작의 안정성을 확보하는 것이 목적입니다.

## 2. 프롬프트 (User Input)

```text
1. "다크 모드일 떄 글자 가독성이 많이 안좋아. 그리고 선택할 수 잇는 날짜는 오늘 기준으로 최대 1년이야"
2. "마우스가 일정 높이 이상에서만 마우스 호버링했을 때 차트에 가격이 보여. 그리고 시뮬레이션에서는 시작 날짜만 보이고 다음 캔들을 눌러야먄 그 다음이 보이게 해줘."
3. "봉을 한국형식으로 바꿀 수 있어?" (빨강=상승, 파랑=하락)
4. "그냥 시뮬레이션으로 접근할 경우 주식과 날짜를 따로 선택할 수 있게 해줘"
```

## 3. AI 응답 요약 (AI Output)

- **UI 개선**: `NewSessionModal`의 다크 모드 스타일 수정 및 날짜 선택 범위(`min`, `max`) 제한 로직 추가.
- **차트 로직 수정**:
    - `lightweight-charts`의 `crosshair` 옵션을 수정하여 Y축 제한 없이 십자선 표시.
    - 초기 데이터 로딩 시 `currentTimeIndex`를 시작 날짜로 설정하여 미래 데이터 숨김.
    - 한국형 캔들 색상(`upColor: #ef4444`, `downColor: #3b82f6`) 적용.
- **구조 리팩토링**:
    - `NewSessionModal`을 `SessionSetupModal`로 공통화.
    - `SimulationPage` 진입 시 URL 파라미터가 없으면 `SessionSetupModal`을 강제로 띄우도록 변경.

## 4. 결과 및 적용 (Result)

### 4.1 세션 설정 공통화
- `src/components/simulation/SessionSetupModal.tsx` 생성.
- 대시보드와 시뮬레이션 페이지 양쪽에서 동일한 설정 UI 사용 가능해짐.
- URL 파라미터 누락 시 강제 설정 유도 구현 완료.

### 4.2 차트 사용성 증대
- **데이터 폴백**: 차트 라이브러리가 스냅핑 문제로 데이터를 놓칠 때, 날짜 기준으로 원본 데이터를 찾아 표시하는 로직 추가.
- **미래 데이터 보호**: 폴백 로직에서도 현재 시뮬레이션 시점보다 미래의 데이터는 절대 보여주지 않도록 `foundIndex <= currentIndex` 조건 추가.

### 4.3 UI 현지화 (Localization)
- KOSPI/KOSDAQ 주요 종목 리스트업.
- 매수(빨강)/매도(파랑) 컬러 시스템을 주문창, 거래 기록, 자산 현황 전반에 일관되게 적용.
