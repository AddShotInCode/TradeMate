# 인덱스 페이지 UI 요소 정리

## 1. 배경 및 목적

- **불필요한 요소 제거**: 인덱스 페이지의 Hero 섹션에 있는 '데모 영상 보기' 버튼은 현재 연결된 영상이 없고 당장 필요하지 않으므로 삭제하여 UI를 정돈합니다.
- **코드 정리**: 사용하지 않는 import 문 등을 함께 정리합니다.

## 2. 프롬프트 (User Input)

```text
인덱스 페이지에서 '데모영상보기' 버튼을 삭제해줘
```

## 3. AI 응답 요약 (AI Output)

- **`HeroSection.tsx` 수정**: '데모 영상 보기' 버튼 요소(`<button>...<span>데모 영상 보기</span>...</button>`)를 삭제했습니다.
- **Import 정리**: 버튼 삭제로 인해 사용하지 않게 된 `Play` 아이콘(`lucide-react`) import를 제거했습니다.

## 4. 결과 및 적용 (Result)

- Hero 섹션에서 불필요한 버튼이 제거되어 사용자에게 보다 명확한 행동(체험하기)을 유도할 수 있게 되었습니다.
