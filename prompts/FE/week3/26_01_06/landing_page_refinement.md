# 랜딩 페이지 콘텐츠 개선 및 로고 분리

## 1. 배경 및 목적

- 초기 구현된 페이지의 내용이 프로토타입 단계에 맞지 않거나(예: 요금제, 과장된 통계), 한국어 문맥이 어색한 부분이 있었습니다.
- 로고가 여러 곳에서 중복 사용되고 있어 재사용 가능한 컴포넌트로 분리할 필요가 있었습니다.

## 2. 프롬프트 (User Input)

```text
1. 지금 인덱스 페이지에 있는 내용을 한글에 맞게 다듬어줘.
2. 내용에서 지금은 프로토타입이니까 부적절한 내용은 삭제해줘(요금 관련 등).
3. 트레이드 메이트의 저 로고를 따로 분리해서 재사용할 수 있게 해줘.
4. 활성 트레이더 등 아직 시작도 안 한 내용은 적절하게 변경해줘.
```

## 3. AI 응답 요약 (AI Output)

- **콘텐츠 수정**: '강제하는 것'을 '제안하는 훈련 과정' 등으로 톤앤매너를 순화하고 자연스럽게 다듬었습니다.
- **프로토타입화**: `StatsSection`의 가상 데이터를 'Beta 서비스', '시장 데이터 연동', '자금 손실 없는 훈련' 등 실제 현황에 맞게 변경했습니다.
- **기능 제거**: 요금제 관련 링크와 버튼을 네비게이션과 CTA 섹션에서 모두 제거했습니다.
- **구조 개선**: `src/components/ui/Logo.tsx` 컴포넌트를 생성하고 `LandingNavigation`, `LandingFooter`에 적용했습니다.

## 4. 결과 및 적용 (Result)

- 사용자에게 잘못된 정보를 주지 않는, 현 단계에 적합한 랜딩 페이지가 되었습니다.
- 로고 컴포넌트를 통해 일관된 브랜딩 관리가 가능해졌습니다.
