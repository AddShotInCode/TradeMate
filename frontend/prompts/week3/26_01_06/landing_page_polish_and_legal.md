# 랜딩 페이지 디자인 수정 및 데이터 고지 추가

## 1. 배경 및 목적

- **가독성 개선**: 메인 헤드라인의 글자 크기가 너무 커서 모바일 등에서 레이아웃이 어색해지는 문제를 해결하기 위해 폰트 크기를 조정합니다.
- **불필요한 요소 제거**: '주요 기능 더 보기' 버튼 등 현재 단계에서 불필요하거나 기능이 없는 UI 요소를 정리합니다.
- **법적 고지 및 출처 명시**: 공공데이터(금융위원회 주식시세정보)를 활용할 예정이므로, 데이터 출처, 갱신 주기(일 1회), 실시간성 여부 등을 명시하여 사용자 혼선을 방지하고 API 활용 규정을 준수합니다.

## 2. 프롬프트 (User Input)

```text
1. 인덱스 페이지에서 시장을 정복하고, 나 자신을 정복하라. 글자 크기를 줄여서 두 줄에 들어오게 해줘.
2. 왜 TradeMate인가요? 에서 주요 기능 더 보기 버튼 삭제 해줘.
3. 푸터에 2026과 함께 주식 정보는 공공데이터 포털에서 금융위원회_주식시세정보... (중략) ...위 내용으로 데이터를 활용할 예정이야. 이 정보로 푸터의 정보를 추가해줘.
```

## 3. AI 응답 요약 (AI Output)

- **`HeroSection.tsx` 수정**: 헤드라인 폰트 사이즈를 `text-4xl` → `text-3xl`, `md:text-6xl` → `md:text-5xl` 등으로 한 단계씩 축소하여 두 줄 내에 안정적으로 배치되도록 했습니다.
- **`FeaturesSection.tsx` 수정**: `주요 기능 더 보기` 버튼 요소를 삭제하고 레이아웃을 정리했습니다.
- **`LandingFooter.tsx` 수정**:
    - Copyright 연도를 2026년으로 업데이트했습니다.
    - 하단에 별도의 섹션을 마련하여 **금융위원회_주식시세정보** API 사용 사실, 데이터 갱신 주기(영업일 D+1), 투자 면책 조항 등을 상세히 기재했습니다.

## 4. 결과 및 적용 (Result)

- 랜딩 페이지의 시각적 완성도가 높아졌습니다.
- 향후 연동될 주식 데이터의 특성(지연 시세 등)을 사용자에게 명확히 고지하여 서비스 신뢰도를 확보했습니다.
