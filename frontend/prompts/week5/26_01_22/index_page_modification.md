# 인덱스 페이지 수정 및 약관 적용 작업

## 1. 배경 및 목적

- **인덱스 페이지 정리**: 불필요한 UI 요소(세션 점수, 작동방식 버튼, 팀/제품 섹션)를 삭제하고 텍스트 스타일을 개선하여 매우 깔끔한 랜딩 페이지를 구성함.
- **약관 적용 개선**: 텍스트 파일로 관리되던 약관을 회원가입 페이지와 인덱스 페이지 푸터에 올바르게 연동하고, API 호출 대신 상수를 사용하여 로딩 속도를 개선함.

## 2. 프롬프트 (User Input)

```text
인덱스 페이지에서 현재 세션 점수 98/100 와 작동방식보기 버튼 삭제해줘

성공적인 트레이딩은 예측이 아닌 대응과 원칙에 있습니다. TradeMate가 제안하는 체계적인 훈련 과정: 글자 크기 줄여서 2줄로 맞춰줘

성공적인 트레이딩은 예측이 아닌 대응과 원칙에 있습니다. TradeMate가 제안하는 체계적인 훈련 과정 : 에서 ':' 삭제해줘

하단에 팀 서비스 소개 블로그 채용 삭제해줘

회원가입 페이지에 있는 privacy_policy와 terms_of_service 파일을 옮겼는데 회원가입 페이지에 변경 내용 적용해주고 인덱스페이지 하단에 있는 개인정보처리방침 이용약관에도 연결해줘

제품 주요 기능 업데이트 삭제해줘
```

## 3. AI 응답 요약 (AI Output)

1. **인덱스 페이지 수정 (`WorkflowSection.tsx`)**
   - "현재 세션 점수 98/100" 오버레이 UI 삭제.
   - "작동방식보기" 버튼 삭제.
   - 설명 텍스트 크기 축소(`text-lg` -> `text-base`) 및 문장 부호(`:`) 제거.

2. **푸터 수정 (`LandingFooter.tsx`)**
   - **팀 섹션 삭제**: "서비스 소개", "블로그", "채용" 링크 제거.
   - **제품 섹션 삭제**: "주요 기능", "업데이트" 링크 제거.
   - **레이아웃 변경**: 링크 섹션이 모두 삭제되고 "법적 고지"만 남음.
   - **약관 연결**: "법적 고지" 링크를 실제 페이지 경로(`/policy/terms`, `/policy/privacy`)로 연결.

3. **약관 상수화 및 페이지 생성**
   - `src/constants/legal_constants.ts`: 약관 텍스트 파일 내용을 상수 변수(`TERMS_OF_SERVICE`, `PRIVACY_POLICY`)로 변환하여 저장.
   - **회원가입 페이지 (`RegisterPage.tsx`)**: API 호출 로직을 제거하고 상수 `import` 방식으로 변경하여 모달에 즉시 표시되도록 최적화.
   - **약관 상세 페이지 생성**:
     - `src/app/policy/terms/page.tsx` (이용약관)
     - `src/app/policy/privacy/page.tsx` (개인정보 처리방침)

## 4. 결과 및 적용 (Result)

- **UI 개선**: 인덱스 페이지가 더 간결해졌으며, 특히 푸터는 "법적 고지"만 남겨두어 필수 정보에 집중하도록 함.
- **성능 최적화**: 약관 내용을 불러올 때 불필요한 네트워크 요청(fetch)을 제거하고 번들링된 상수를 사용하여 즉시 로딩됨.
- **UX 향상**: 약관 관련 접근성을 높이고, 빠른 페이지 전환 및 모달 표시에 기여함.
