# AI Prompts 저장 컨벤션

이 폴더는 프로젝트 개발 과정에서 유의미한 결과를 도출했거나, 복잡한 문제를 해결한 AI 프롬프트를 기록하고 공유하기 위한 공간입니다.

## 1. 저장 기준

- **코드 변경 수락**: AI가 생성한 코드가 실제 프로젝트에 반영된 경우.
- **문제 해결**: 버그 수정, 리팩토링, 성능 개선 등 구체적인 문제를 해결한 경우.
- **유용한 인사이트**: 코드 구조 설계, 기술 스택 선정 등 중요한 의사결정에 도움을 준 경우.

## 2. 디렉토리 및 파일 구조

- **경로**: `prompts/week{n}/{YY_MM_DD}/{기능_또는_주제}.md`
- **예시**: `prompts/week1/25_12_24/로그인_API_구현.md`

## 3. 파일 명명 규칙 (Naming Convention)

- **형식**: `snake_case` 사용 권장
- **내용**: 해당 프롬프트의 핵심 주제나 기능을 명확하게 표현
- **예시**:
  - `login_api_implementation.md` (O)
  - `fix_infinite_scroll_bug.md` (O)
  - `20251224.md` (X) - 주제를 알 수 없음

## 4. 문서 작성 템플릿

각 프롬프트 파일은 아래 형식을 따릅니다.

```markdown
# {주제/기능 이름}

## 1. 배경 및 목적

- 어떤 작업을 수행하려고 했는지, 어떤 문제가 있었는지 간단히 기술

## 2. 프롬프트 (User Input)

\`\`\`text
(여기에 실제로 사용한 프롬프트 내용을 붙여넣으세요)
\`\`\`

## 3. AI 응답 요약 (AI Output)

- AI가 제안한 해결책, 코드 스니펫, 또는 설명의 핵심 내용

## 4. 결과 및 적용 (Result)

- 실제 코드에 어떻게 적용되었는지
- 추가적인 수정 사항이 있었는지
- 배운 점이나 특이사항
```

## 5. 기타

- 스크린샷이나 관련 링크가 있다면 함께 첨부합니다.
- 민감한 정보(API Key, 비밀번호 등)는 반드시 마스킹 처리 후 업로드합니다.
