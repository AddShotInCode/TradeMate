# 경향성/원칙 설정 페이지 구현

## 1. 배경 및 목적

제공된 HTML을 기반으로, 사용자의 주식 투자 경향성과 투자 원칙을 입력받는 페이지를 Next.js 컴포넌트로 제작해야 합니다. 
랜딩 페이지의 네비게이션과 푸터를 재사용하여 일관된 사용자 경험을 제공합니다.

## 2. 프롬프트 (User Input)

### 프롬프트 1: 초기 페이지 구현
```
tmp_propensity.html의 디자인을 바탕으로 사용자에게 주식 투자 경향성,투자원칙을 입력받는 페이지를 제작해줘. 단, 인덱스페이지의 네비게이션과 푸터는 그대로 사용해줘.
```

### 프롬프트 2: UI 개선
```
1. TradingStyleSelector의 '주요 투자 스타일' 택스트 옆에 ?가 써져있는 작은 동그라미 버튼을 추가하고 이 버튼 클릭 시 스캘핑, 데이트레이딩, 스윙에 대한 간략한 설명을 대화창처럼 띄우는 기능을 추가해줘.
2. 위험 성향 슬라이더의 양 끝에 있는 '보수적', '적극적' 텍스트를 살짝만 하단에 배치해줘. 지금은 슬라이드와 겹쳤어.
3. 숫자 입력하는 칸 3개에 전부 값 조절하는 위아래버튼이 있는데 제거해줘.
```

## 3. AI 응답 요약 (AI Output)

### 3.1 생성된 파일 구조

**페이지:**
- `src/app/propensity/page.tsx` - 메인 페이지

**컴포넌트 (`src/components/propensity/`):**
- `TradingStyleSelector.tsx` - 투자 스타일 선택 (스캘핑/데이트레이딩/스윙)
- `RiskAppetiteSlider.tsx` - 위험 성향 슬라이더
- `MaxLossInput.tsx` - 일일 최대 손실 한도 입력
- `PropensityAssessment.tsx` - 투자 성향 분석 섹션 (위 3개 통합)
- `StrategyTemplateCard.tsx` - 전략 템플릿 카드
- `StrategyTemplates.tsx` - 전략 템플릿 선택 섹션
- `PrincipleItem.tsx` - 개별 원칙 항목
- `PrinciplesCustomizer.tsx` - 투자 원칙 설정 섹션
- `ActionBar.tsx` - 하단 액션 바

### 3.2 주요 기능

1. **투자 성향 분석**
   - 투자 스타일 선택 (스캘핑/데이트레이딩/스윙)
   - 위험 성향 슬라이더 (매우 보수적 ~ 매우 적극적)
   - 일일 최대 손실 한도 설정

2. **전략 템플릿 선택**
   - 추세 추종 (Trend Follower)
   - 돌파 매매 (Breakout Trader)

3. **투자 원칙 커스터마이징**
   - 거래당 최대 위험 (%)
   - 중요 뉴스 발표 시 거래 금지
   - 최대 동시 보유 포지션
   - 토글 스위치로 활성화/비활성화
   - 사용자 정의 원칙 추가 버튼

4. **액션 바**
   - 활성화된 원칙 개수 표시
   - 임시 저장 버튼
   - 저장 후 훈련 시작 버튼

## 4. 결과 및 적용 (Result)

- 사용자가 자신의 성향대로 투자 경향을 맞춤 설정을 할 수 있습니다.
- 직관적인 UI로 투자 성향과 원칙을 쉽게 입력하고 수정할 수 있습니다.
