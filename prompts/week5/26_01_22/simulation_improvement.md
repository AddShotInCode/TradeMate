# 시뮬레이션 페이지 UI/UX 개선 및 기능 고도화

## 1. 배경 및 목적

- **시뮬레이션 현실성 강화**: 실제 거래소와 유사한 주문 경험을 제공하고, 비현실적인 요소(예: 의도치 않은 슬리피지, 잘못된 진입가 계산)를 제거함.
- **사용자 편의성 증대**: 반복적인 입력 작업(SL/TP)을 자동화하고, 직관적인 UI(매수/매도 분리)를 도입하여 사용성을 개선함.
- **버그 수정 및 안정성 확보**: React 렌더링 오류(Key prop missing) 및 UI 상호작용(크기 조절) 오류를 수정함.

## 2. 프롬프트 (User Input)

```text
1. OrderForm 수정:
   - 숫자 입력할때 50원씩 계속 붙는데 이거 왜이러지? 0으로 해줘.
   - 주문 창 디자인 수정해줘. 매수 매도 창 분리.
   - 매도 수량은 내가 보유하고 있는 주식에서 해야해. 보유 수량 넘지 않게 막아줘.
   - 매수는 왜 long이고 매도는 short 이야? 헷갈리니까 그냥 '매수', '매도'로 해줘.

2. 기능 추가:
   - 손절(SL)/익절(TP) 입력 필수(Mandatory)로 해줘. 안쓰면 경고창 띄워줘.
   - 매수할 때 진입가(Entry Price)는 현재가로 고정되게 해줘. 수정 못하게.
   - SL/TP는 진입가 기준으로 자동 계산되게 해줘 (예: -2%, +4%). 물론 수정 가능하게.
   - 손익비(Risk/Reward) 표시는 굳이 필요 없어. 지워줘.
   - 수량 조절할 때 슬라이더(Bar) 추가해서 쉽게 조절하게 해줘.

3. UI 버그 및 기타 수정:
   - 거래 기록(TradeLog) 섹션 크기 조정이 안돼. 마우스 올리면 커서는 변하는데 안 움직여.
   - 차트 화면 부분은 크기가 변경이 안돼.
   - 차트 간격을 1D, 1W, 1M, 3M, 1Y으로 변경해줘.
   - TradeLog 렌더링 시 key값 에러 나는거 고쳐줘.
```

## 3. AI 응답 요약 (AI Output)

1.  **주문 폼 (`OrderForm.tsx`) 전면 개편**
    *   **탭 분리 및 로직 차별화**:
        *   **매수(Buy) 탭**: 'New Position' 진입 전용. 잔고(`Balance`) 기준 최대 수량 계산.
        *   **매도(Sell) 탭**: 'Close Position' 청산 전용. 보유 포지션(`Open Positions`) 기준 최대 수량 계산. 부분 익절/손절 지원.
    *   **UX 개선**:
        *   **진입가 고정**: `currentPrice`로 자동 고정 및 `readOnly` 처리.
        *   **SL/TP 자동 계산**: 진입가 대비 SL(-2%), TP(+4%) 기본값 자동 입력 (수정 가능).
        *   **필수 입력 검증**: SL/TP 미입력 시 `alert` 경고 및 주문 차단.
        *   **용어 단순화**: 'Long/Short' 등의 용어 대신 직관적인 **'매수'**, **'매도'** 라벨 사용.
        *   **수량 슬라이더**: 최대 가능 수량 범위 내에서 조절 가능한 Range Slider 추가. 보유량 초과 방지 클램핑(Clamping) 로직 적용.

2.  **시뮬레이션 스토어 (`simulationStore.ts`) 로직 수정**
    *   **슬리피지 제거**: 주문(`placeOrder`) 및 청산(`closePosition`) 시 강제로 +/- 50원 붙던 비현실적인 로직 삭제.
    *   **부분 청산(`sellPosition`) 추가**: FIFO(선입선출) 방식으로 보유 수량의 일부만 청산하는 로직 구현.

3.  **UI 상호작용 및 레이아웃 수정 (`TradeLog.tsx`, `ChartControls.tsx`, `SimulationChart.tsx`)**
    *   **TradeLog 리사이징 고도화**:
        *   기존 `window` 이벤트 리스너 방식의 불안정성을 `useRef`와 `globalThis.MouseEvent`를 활용한 로직으로 전면 재작성.
        *   부모 Flex 컨테이너의 압축 방지를 위해 `flex-none` 적용 및 차트 영역에 `min-h-0` 추가로 유연한 크기 조절 구현.
        *   드래그 핸들 히트 영역(Hit Area)을 확장하여 사용성 개선.
    *   **차트 반응형 수정**: `ResizeObserver`를 도입하여 TradeLog 크기 변화 시 차트 높이가 즉시 자동 조절되도록 수정.
    *   **차트 간격(Interval) 변경**: `1D, 1W, 1M, 3M, 1Y`로 변경 및 선택 상태 UI 적용.
    *   **React Key Error 수정**: `Fragement`를 사용하여 매핑 시 고유 `key` prop 정상 적용.

## 4. 결과 및 적용 (Result)

- **사용성 대폭 향상**: 초보자도 헷갈리지 않는 직관적인 주문 프로세스 구축 (매수/매도 탭 분리, 자동 계산 등).
- **현실성 강화**: '50원 틱' 오류 수정 및 보유량 기반의 엄격한 매도 로직 적용.
- **UI 완성도**: 드래그 앤 드롭 리사이징, 반응형 차트 등 디테일한 인터랙션 품질 확보.
