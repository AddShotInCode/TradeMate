# 시뮬레이션 리포트 UI 개선 및 대시보드 정리

## 1. 배경 및 목적

- 시뮬레이션 목록 테이블의 가독성 및 정렬 개선.
- 대시보드에서 불필요한 통계 카드(원칙 준수율, 평균 수익률) 제거를 통한 UI 간소화.
- 시뮬레이션 결과 리포트 페이지의 불필요한 정보(차트, 최종 평단가) 제거 및 주요 통계(투자금, 수익률, 손익)의 시인성 강화.
- 원칙 분석 결과 텍스트를 더 구체적이고 자연스럽게 다듬기.

## 2. 프롬프트 (User Input)

1. "관리와 삭제 버튼을 같은 열로 맞추면 좋겠어"
2. "대쉬보드에 원칙 준수율, 평균 수익률을 삭제해줘"
3. "종목(코드) 시작일 종료일 상태 생성일 분석 관리 텍스트 중앙정렬해줘"
4. "리포트 페이지의 평가 상세 차트와 최종 평단가 카드를 삭제하고, 남은 카드(총 투자금, 누적 수익률, 실현 손익)의 높이를 평가 시스템 카드와 맞춰줘"
5. "원칙 분석에 대한 문장을 자연스럽게 다 다듬어줘"
6. "총 투자금, 누적 수익률, 실현 손익 글자 크기를 키우고 수평/수직 중앙 정렬해줘"

## 3. AI 응답 및 적용 내용 (Result)

### 3.1 시뮬레이션 목록 (`AllSimulationsList.tsx`)

- 테이블 헤더와 데이터 셀(td)에 `text-center` 및 `whitespace-nowrap` 적용하여 텍스트 정렬 통일.
- '관리' 컬럼을 '분석'과 '관리'(삭제)로 분리하려던 시도가 있었으나 최종적으로는 텍스트 정렬을 통해 깔끔하게 정리됨.

### 3.2 대시보드 (`dashboard/page.tsx`, `StatsGrid.tsx`)

- `StatsGrid` 컴포넌트 삭제 및 `page.tsx` 내 참조 제거.
- 헤더와 최근 세션 목록만 남도록 레이아웃 정리.

### 3.3 시뮬레이션 리포트 (`simulation/[id]/report/page.tsx`)

- **레이아웃 변경**:
  - '최종 평단가' 카드 삭제.
  - 하단의 '평가 상세' 바 차트 영역 삭제.
  - 상단 통계 카드 그리드를 `grid-cols-4` → `grid-cols-3`으로 변경하여 공간 활용 최적화.
- **스타일링 개선**:
  - 주요 지표(총 투자금, 누적 수익률, 실현 손익)의 폰트 크기를 `text-2xl` → `text-4xl`로 확대.
  - 카드 내 컨텐츠를 `flex-col justify-center text-center`를 사용하여 수직/수평 중앙 정렬 배치.
  - 아이콘 크기 확대 (`w-8` → `w-10`) 및 패딩 증가.
- **텍스트 개선**:
  - 원칙 분석(Principle Analysis) 섹션의 조건부 렌더링 메시지를 점수 구간(80점 이상, 50점 이상, 50점 미만)에 따라 구체적이고 자연스러운 문장으로 수정.
    - 예: "흔들림 없이 원칙을 지키며...", "대체로 원칙을 따랐으나...", "잦은 뇌동매매나..."
