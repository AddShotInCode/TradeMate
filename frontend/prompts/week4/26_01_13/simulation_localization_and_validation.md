# 시뮬레이션 금액 단위 변경 및 유효성 검사

## 1. 배경 및 목적

- 미 달러($) 단위를 한국 원화(₩)로 변경하여 국내 사용자 친화적인 환경 제공.
- 데이터 단위를 일봉(Daily) 기준으로 가정하고 이에 맞춰 더미 데이터 및 스케일 조정.
- 주문 폼에서 음수 입력 방지 등 유효성 검사 강화.

## 2. 프롬프트 (User Input)

```text
디자인을 기반으로 시뮬레이션 페이지를 구현해줘.
라이브러리를 활용해서 차트를 구현해줘.
달러를 원으로 바꾸고 데이터는 일단위로 주어질 것 같아. 손절가와 목표가는 음수가 불가능하게 해줘.
```

## 3. AI 응답 요약 (AI Output)

- **Store 수정**: 초기 자본금($100,000 → 1억 원), 제품 가격, 수수료 등을 원화 스케일에 맞춰 조정.
- **UI 수정**: `StatsBar`, `ChartControls`, `TradeLog`, `OrderForm`에서 통화 기호를 `$`에서 `₩`으로 변경하고 소수점 제거 포맷팅 적용.
- **Input 검증**: `OrderForm`의 수량 및 가격 입력 필드에 `min="0"` 속성 추가 및 주문 실행 전 유효성 검사 로직 보완.
- **Chart 데이터 수정**: 더미 데이터를 원화 가격대(~15만원 선)로 업데이트.

## 4. 결과 및 적용 (Result)

- 시뮬레이션 페이지 전반에 원화 단위 적용 완료.
- 비현실적인 가격 데이터(일봉 기준) 수정.
- 사용자 입력 실수 방지를 위한 최소한의 유효성 검사 장치 마련.
