📊 [TradeMate] 백엔드 핵심 알고리즘 및 비즈니스 로직 설계

본 문서는 TradeMate 시뮬레이션의 핵심인 **'원칙 준수 채점 알고리즘'**과 '이동평균 기반 평단가 관리' 로직에 대한 상세 설계안입니다.

1. 개별 매도 건별 점수 ($s_i$) 설계

매도 시점의 평단가($P_{avg}$)를 기준으로 **익절(Profit)**과 손절(Loss) 상황을 분리하여 채점합니다. 수익률 자체보다 '설정한 계획을 얼마나 엄격히 이행했는가'에 가중치를 둡니다.

[공통 원칙]

모든 점수는 $0 \sim 100$점 사이로 산출됩니다.

수식 결과가 음수일 경우 $\max(0, \text{점수})$를 통해 $0$점으로 보정합니다.

기본 공식:


$$s_i = \max\left(0, \frac{R + C}{2} \times 100\right)$$

$R$ (Result): 수익 결과 점수 (성과 평가)

$C$ (Compliance): 원칙 준수 점수 (계획 이행 평가)

① 익절 시 ($P_{sell} \ge P_{avg}$)

익절 상황에서는 수익이 확보되었으므로 결과 점수는 만점을 부여하되, 매도 가격이 목표가($T$)와 얼마나 일치하는지를 평가합니다.

결과 점수 ($R$): $1.0$ (고정)

설명: 수익 창출이라는 일차적 목적을 달성했으므로 만점을 부여합니다.

과정 점수 ($C$):

목표가 미달 또는 도달 시 ($P_{sell} \le T$):


$$\max\left(0, 1.0 - \frac{|T - P_{sell}|}{|T - P_{avg}|}\right)$$

의도: 목표가($T$)에 미달하여 너무 일찍 팔수록(공포 매도) 감점됩니다.

목표가 초과 시 ($P_{sell} > T$):


$$\max\left(0, 1.0 - \frac{0.5 \times (P_{sell} - T)}{|T - P_{avg}|}\right)$$

의도: 목표가보다 비싸게 파는 것은 '탐욕'으로 간주하되, 수익 극대화 측면을 고려하여 페널티를 $50\%$ 감면합니다.

② 손절 시 ($P_{sell} < P_{avg}$)

손절 상황에서는 원금 회수율과 더불어 '약속한 손절가($S$)'를 지켰는지를 엄격하게 평가합니다.

결과 점수 ($R$): $\frac{P_{sell}}{P_{avg}}$

설명: 평단가 대비 실제 회수한 금액의 비율입니다. (예: $10\%$ 손실 시 $0.9$)

과정 점수 ($C$):

손절가 위에서 대응 시 ($P_{sell} \ge S$): $1.0$

의도: 손절가 도달 전 혹은 정확히 손절가에서 매도했다면 원칙을 준수한 것으로 간주합니다.

손절가 아래에서 대응 시 ($P_{sell} < S$):


$$\max\left(0, 1.0 - \frac{S - P_{sell}}{|S - P_{avg}|}\right)$$

의도: 정해둔 손절가($S$)보다 더 떨어질 때까지 방치(희망 회로)하다가 판 경우, 이탈 거리만큼 가혹하게 감점합니다.

2. 최종 세션 종합 점수 ($S_{Total}$) 설계

시뮬레이션 전체 세션에 대한 종합 평가 지표로, 매매 비중에 따른 가중 평균을 사용합니다.

공식:


$$S_{Total} = \sum_{i=1}^{n} \left(s_i \times \frac{q_i}{Q_{Total}}\right)$$

설계 의도: 소량 매매보다 비중이 큰 매매에서 원칙을 지키는 것이 계좌에 더 큰 영향을 미치므로, 매도 수량($q_i$)의 비중을 가중치로 적용합니다.

3. 수익성 지표 산출 (Profitability Metrics)

원칙 점수와 별개로 실제 투자 성과를 측정하기 위한 지표입니다.

개별 거래 수익률 (ROI):


$$\text{ROI} (\%) = \frac{P_{sell} - P_{avg}}{P_{avg}} \times 100$$

개별 실현 수익금 (Realized Profit):


$$\text{Profit} = (P_{sell} - P_{avg}) \times q_i$$

세션 누적 수익률 (Total Session ROI):


$$\text{Total ROI} (\%) = \frac{\sum \text{Realized Profit}}{\text{Total Investment}} \times 100$$

4. 핵심 비즈니스 로직: 평단가 ($P_{avg}$) 관리

시뮬레이션 중 사용자의 자산 상태를 추적하기 위해 이동평균법을 사용합니다.

① 평단가 갱신 (매수 시)

매수 시점에만 평단가가 갱신되며, 매도 시에는 이전 평단가가 유지됩니다.

계산 공식:


$$P_{avg\_new} = \frac{(P_{avg\_old} \times Q_{old}) + (P_{buy} \times Q_{new})}{Q_{old} + Q_{new}}$$

② 평단가 유지 및 초기화 (매도 시)

매도 시에는 보유 수량(Balance)만 감소하며, $P_{avg}$는 변하지 않습니다.

매도 시 저장된 $P_{avg}$를 불러와 $s_i$ 점수 산출 로직에 투입합니다.

보유 수량이 $0$이 되면 평단가 기록을 초기화합니다.

5. 주요 데이터 필드 정의

| 필드명    | 타입    | 수식 변수 | 상세 설명                  |
|-----------|---------|-----------|---------------------------|
| timestamp | Date    | -         | 거래 발생 시간 (ISO 8601) |
| balance   | Integer | -         | 거래 전 보유 수량         |
| price     | Integer | $P_{sell}$ | 실제 체결 가격            |
| upper     | Integer | $T$       | 매수 시 설정한 상한가 (Target Price) |
| lower     | Integer | $S$       | 매수 시 설정한 하한가 (Stop Loss) |
| type      | String  | -         | 거래 종류 (B: Buy, S: Sell) |
| volume    | Integer | $q_i$     | 거래 수량                 |
| p_avg     | Float   | $P_{avg}$ | 매도 시점의 이동평균 평단가 |

6. 구현 지침 (AI 개발 가이드)

Divide by Zero 방지:

$T$, $S$가 $P_{avg}$와 동일하거나 $P_{avg}$가 $0$인 경우에 대비하여 분모가 $0$이 될 때의 예외 처리를 반드시 포함하십시오. (기본값으로 과정 점수 $1.0$ 반환 권장)

소수점 정밀도 (BigDecimal):

금융 연산이므로 부동 소수점 오차 방지를 위해 double 대신 BigDecimal을 사용하십시오.

나눗셈 연산 시 RoundingMode.HALF_UP을 적용하고 소수점 8자리 이상 유지 후 최종 결과에서 반올림하십시오.

불변성 유지:

각 거래 기록은 생성 후 수정되지 않도록 불변(Immutable) 객체로 다루십시오.
