3. 핵심 지표 해석 가이드

3.1 결과 점수 (R)

의미: 투자 매매를 통해 발생한 실제 수익성 및 자산 보존 능력을 평가합니다.

기준: 평단가(P_avg) 대비 실제 매도가(P_sell)의 비율을 측정합니다. 익절(수익) 상황에서는 계획한 수익권 진입에 성공한 것이므로 무조건 100점을 부여하며, 손절(손실) 상황에서는 자산을 얼마나 방어했느냐(회수율)에 따라 점수가 산출됩니다.

3.2 과정 점수 (C)

의미: 매수 시 수립한 매매 가설(상한/하한가)을 실제 매도 시점에서 얼마나 기계적으로 이행했는지 '통제력'을 평가합니다.

특징: 수익의 크기보다 '약속 이행'에 집중합니다. 설정한 익절가(T)나 손절가(S)에서 벗어날수록 감점됩니다. 단, 목표가를 넘어선 초과 수익 시에는 시장 흐름에 따른 유연한 대응을 인정하여 페널티를 50% 감면해주는 보너스 룰이 적용됩니다.

4. 보고서 구성 및 항목 상세 설명

본 시뮬레이션 결과 보고서는 사용자의 직관적인 복기를 위해 '1. 시뮬레이션 요약', '2. 매도 건별 상세 분석 내역', '3. 핵심 지표 해석 가이드'의 세 가지 핵심 섹션으로만 구성되어 출력됩니다.

4.1 시뮬레이션 요약 (Summary)

사용자가 시뮬레이션 시작 시 설정한 기본 조건과 전체 세션의 성적표입니다. 특히 '최종 종합 점수'는 단순히 매매 횟수로 나누지 않고 수량 비중(가중치)을 반영하여, 큰 금액의 매매에서 원칙을 얼마나 잘 지켰는지를 종합적으로 보여줍니다.

4.2 매도 건별 상세 분석 내역

각 매도 거래 건에 대한 상세 성적 리스트입니다. 매 시점의 가격 변동 및 사용자가 설정한 상/하한가 원칙을 바탕으로 순수 매매 원칙 이행도를 건별 점수(s_i)로 환산하여 제공합니다.

4.3 핵심 지표 해석 가이드 (결과 점수와 과정 점수)

결과 점수 (R): '결과가 좋았는가?'를 묻습니다. 자산의 회수율을 측정하여 투자자로서 자산을 지키는 능력을 점수화합니다.

과정 점수 (C): '매매 방식이 옳았는가?'를 묻습니다. 뇌동매매를 방지하고 자신이 세운 시나리오대로 움직였는지 감정 제어 능력을 측정합니다.

5. 기타 용어 정의

최종 평단가 (P_avg): 모든 매수 기록을 이동평균법으로 합산한 최종 평균 매입가입니다.

상한 (T) / 하한 (S): 사용자가 해당 주식을 보유할 당시 설정했던 목표 매도가(Target)와 손절 기준가(Stop-loss)입니다.

최종 수익률 (Total ROI): 시뮬레이션 전체 과정에서 투입된 원금 대비 실현된 총 수익의 비율입니다.

최종 종합 점수 (S_Total): 세션 내 모든 매도 점수를 거래 수량 비중으로 합산한 최종 투자 성적표입니다. 산출 공식은 Σ (s_i * (q_i / Q_Total))를 따릅니다.
