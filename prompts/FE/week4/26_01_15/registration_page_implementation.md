# Registration Page Implementation

## 1. 배경 및 목적

- 로그인 페이지에서 회원가입으로 이동하는 플로우가 필요
- 제공된 HTML 디자인(`tmp_registration.html`)을 기반으로 Next.js(App Router) 회원가입 페이지를 구축
- 입력값 검증(이메일/비밀번호/전화번호/동의), 이메일 인증(코드 발송/검증), 개인정보처리방침 팝업, 가입 후 대시보드 이동까지 FE 프로토타입을 완성

## 2. 프롬프트 (User Input)

```text
- 회원가입 페이지를 만들고, 로그인 페이지의 회원가입 버튼으로 이동하게 해줘. 제공한 tmp_registration.html 디자인 기반.
- 이름/이메일 사이에 생년월일 입력(연/월/일 드롭다운) 추가. 연도 범위는 (현재연도-100)~(현재연도), 해가 바뀌면 자동 갱신.
- 조건 검사 기능 추가:
  - 이메일 형식(정규식)
  - 이메일 인증(UI 버튼만 -> 이후 실제 구현)
  - 비번 형식(알파벳/숫자/특수기호 포함 & 8자리 이상)
  - 비번 재입력 일치
  - 전화번호(빈칸 또는 숫자 11자리)
  - 회원가입 버튼(모든 조건 + 필수동의 체크 시 활성화)
- 이메일 인증을 실제 동작하게:
  - 이메일 입력 후 인증 버튼 누르면 6자리 난수 발송
  - 인증코드 입력 시 인증 성공
- 인증 자동 검증(6자리 입력 시 자동 확인)
- Gmail SMTP로 실제 발송하고 환경변수 설정 방법 안내
- 인증코드 유효시간 5분, 만료 후 인증 불가 + 타이머 UI 표시
- 이용약관 클릭 시 파일 내용을 중앙 팝업으로 표시
- 개인정보처리방침 클릭 시 파일 내용을 중앙 팝업으로 표시
- 개인정보처리방침 문서 가독성 개선(마크다운 기호 제거/번호 정리/들여쓰기/줄바꿈 규칙 적용)
- 회원가입 버튼 클릭 시 대시보드로 이동
- 대시보드 사이드바 하단에 사용자 이름 버튼을 다른 버튼과 같은 스타일로 표시
```

## 3. AI 응답 요약 (AI Output)

- 페이지/라우팅
  - `/register` 페이지 추가 및 UI 구현
  - 로그인 페이지의 회원가입 링크를 `/register`로 연결

- 입력 UI/검증
  - 생년월일(연/월/일) 드롭다운 추가
  - 이메일/비밀번호/비밀번호확인/전화번호/필수동의 검증에 따라 회원가입 버튼 활성화
  - 전체 텍스트 한글화

- 이메일 인증(서버 + 클라이언트)
  - 인증번호 6자리 발송 API: `POST /api/auth/email-code`
  - 인증번호 검증 API: `POST /api/auth/verify-email-code`
  - `nodemailer` 기반 SMTP 발송(환경변수 `SMTP_*`)
  - 인증코드 5분 TTL 적용 및 만료 시 인증 불가
  - 인증코드 입력 6자리 완료 시 자동 검증
  - 인증코드 입력칸 하단에 5분 카운트다운 표시

- 이용약관/개인정보처리방침 팝업
  - 이용약관/개인정보처리방침 파일을 API로 읽어서 모달 중앙 팝업으로 표시

- 가입 완료 후 흐름
  - 가입 성공(프로토타입) 시 `/dashboard`로 이동
  - 사이드바 최하단에 로컬 저장된 사용자 이름(`tm_userName`) 버튼 표시

## 4. 결과 및 적용 (Result)

- 주요 변경/추가 파일
  - `src/app/register/page.tsx`
  - `src/app/login/page.tsx`
  - `src/app/api/auth/email-code/route.ts`
  - `src/app/api/auth/verify-email-code/route.ts`
  - `src/app/api/legal/privacy-policy/route.ts`
  - `src/app/register/terms_of_service.txt`
  - `src/app/register/privacy_policy.txt`
  - `src/components/layout/Sidebar.tsx`
  - `package.json` (`nodemailer`, `@types/nodemailer`)
  - `.env.example` (SMTP 예시)

- 동작 요약
  - 회원가입 폼은 필수 입력 + 이메일 인증 완료 + 필수 약관 동의 시에만 제출 가능
  - 이메일 인증은 Gmail SMTP(앱 비밀번호)로 발송 가능
  - 인증코드는 5분 유효, 타이머 만료 후 인증 불가
  - 이용약관/개인정보처리방침은 파일 기반으로 모달에서 바로 확인 가능
  - 회원가입 후 대시보드로 이동하며, 사이드바 하단에 사용자 이름 표시

- 주의사항
  - SMTP 비밀번호는 절대 커밋하지 않고 로컬/배포 환경변수로만 관리(예: `.env.local`)
  - 현재 인증코드 저장소는 메모리(Map) 기반이므로, 프로덕션/멀티 인스턴스 환경에서는 Redis/DB 등 공유 저장소로 교체 필요
