# 시뮬레이션 기능 개선 및 리팩토링 (2026-01-27)

## 1. 배경 및 목적

- **목적**: 시뮬레이션의 매매 경험을 개선하고, 불필요한 UI 요소를 제거하며, 유지보수성을 높이기 위한 리팩토링 수행.
- **주요 문제점 및 요구사항**:
  - 자동 매매(SL/TP) 실행 시 명확한 피드백 부재 및 피드백 방식 변경 요청.
  - 자동 매매 기능의 완전 비활성화 및 수동 매매 원칙 강화.
  - 주문 화면(OrderForm)의 사용성 개선 (슬라이더, 입력 필수화 등).
  - 차트 컨트롤 및 거래 기록의 불필요한 UI 제거.
  - 하드코딩된 종목 리스트의 상수화 및 재사용성 확보.

## 2. 프롬프트 (User Input)

```text
1. 시뮬레이션 스토어 업데이트해서 자동 매매(SL/TP) 시 [Stop Loss], [Take Profit] 태그 추가해줘.
2. 스탑 로스 판매는 안해도 돼 (자동 매매 비활성화). 
3. 익절도 자동은 비활성화해주고, 손절/목표가 입력 필수화 및 슬라이더 추가해줘.
4. 예상 손익 표기(+, - 위치) 조정해줘.
5. 추가 매수(물타기) 시에는 손절/목표가 설정 못하게 해줘.
6. 거래 기록에서 수수료(Fee) 컬럼 삭제해줘.
7. 차트 컨트롤에서 '이전' 버튼 삭제해줘.
8. 관리 대상 종목 리스트를 상수 파일로 분리하고 시뮬레이션 시작 모달에도 적용해줘.
```

## 3. AI 응답 요약 (AI Output)

- **시뮬레이션 로직 변경**: `simulationStore.ts` 수정
  - 자동 매매(SL/TP 도달 시 청산) 로직 주석 처리 (비활성화).
  - 단, SL/TP 도달 여부 체크 로직은 남겨두어 필요 시 수동 청산 가이드로 활용 가능성 열어둠.
  
- **주문 화면(`OrderForm.tsx`) 개선**:
  - **입력 강제**: 초기 진입 시 손절가/목표가 입력 필수화.
  - **슬라이더 추가**: 손절(0~20%), 익절(0~50%) 설정 가능한 퍼센트 슬라이더 도입.
  - **추가 매수 제한**: 보유 수량이 있을 경우 SL/TP 입력란 비활성화 및 안내 문구 표시.
  - **UI 수정**: 예상 손익 표기 방식 변경 (`-₩10,000` 등).

- **UI 단순화**:
  - `TradeLog.tsx`: 수수료 컬럼 제거 및 테이블 레이아웃 조정.
  - `ChartControls.tsx`: '이전' 버튼 삭제.

- **리팩토링**:
  - `src/constants/targetStocks.ts` 생성: 종목 리스트 분리.
  - `SessionSetupModal.tsx` 수정: 상수 파일 import하여 종목 목록 렌더링.

## 4. 결과 및 적용 (Result)

### 적용 파일
- `src/store/simulationStore.ts`: 자동 매매 로직 비활성화.
- `src/components/simulation/OrderForm.tsx`: 유효성 검사 강화, 슬라이더 추가, 추가 매수 제한 로직.
- `src/components/simulation/TradeLog.tsx`: 수수료 컬럼 삭제.
- `src/components/simulation/ChartControls.tsx`: 이전 버튼 삭제.
- `src/constants/targetStocks.ts`: 종목 상수 파일 생성.
- `src/components/simulation/SessionSetupModal.tsx`: 종목 상수 적용.

### 개선 효과
- 사용자가 매매 원칙(손절/목표가)을 지키면서도 자동 매도에 의존하지 않고 직접 결정할 수 있는 환경 조성.
- UI 직관성 향상 및 화면 공간 효율화.
- 종목 리스트 관리가 한 곳에서 이루어져 유지보수 용이성 증대.
