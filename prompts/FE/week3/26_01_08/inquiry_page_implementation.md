# 주식 조회 페이지 구현

## 1. 배경 및 목적

제공된 HTML을 기반으로, 주식 조회 페이지를 Next.js 컴포넌트로 제작해야 합니다. 
랜딩 페이지의 네비게이션과 푸터를 재사용하여 일관된 사용자 경험을 제공합니다.

## 2. 프롬프트 (User Input)

### 프롬프트 1: 초기 페이지 구현
```
tmp_inquiry.html의 디자인을 기반으로 주식 조회 페이지를 만들어줘. 단, 인덱스 페이지의 네비게이션과 footer는 그대로 포함해야해.
```

### 프롬프트 2: 컴포넌트 정리 및 한글화
```
1. newsfeed와 simulationbanner와 관련된 부분 다 제거해줘.
2. 주식 이름 같은 고유명사를 제외한 나머지 부분을 한글로 변경해줘.
```

## 3. AI 응답 요약 (AI Output)

### 3.1 생성된 파일 구조

**페이지:**
- `src/app/inquiry/page.tsx` - 메인 페이지

**컴포넌트 (`src/components/inquiry/`):**
- `InquiryNavigation.tsx` - 앱 전용 네비게이션 (참고용)
- `WatchlistSidebar.tsx` - 좌측 사이드바 (검색, 워치리스트)
- `StockDetailView.tsx` - 메인 상세 뷰
- `StockHeader.tsx` - 주식 헤더 정보
- `StockChart.tsx` - 차트 섹션
- `KeyStats.tsx` - 주요 통계
- `FundamentalData.tsx` - 펀더멘털 데이터
- `PrincipleCheck.tsx` - 원칙 체크 카드

### 3.2 주요 기능

1. **반응형 디자인** - 모바일/데스크톱 모두 지원
2. **워치리스트 사이드바** - 검색, 탭(관심종목/최근 조회), 종목 선택
3. **실시간 주식 정보** - 가격, 변동률, 차트
4. **펀더멘털 데이터** - 시가총액, P/E, 배당수익률 등
5. **원칙 체크** - TradeMate 고유 기능 (매매 원칙 기반 체크리스트)
6. **인덱스 페이지의 네비게이션과 푸터** 재사용


## 4. 결과 및 적용 (Result)

- 사용자가 원하는 주식을 조회할 수 있는 페이지가 제작되었습니다.
- 기본 정보를 표로 정리하고 차트를 통해 주식 현황을 시각화함으로써 페이지의 가독성을 향상시킵니다.
