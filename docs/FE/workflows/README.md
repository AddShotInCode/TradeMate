# 워크플로우 문서

TradeMate 프로젝트의 개발 워크플로우 및 자동화 스크립트를 정리한 문서입니다.

## 📑 목차

### 워크플로우

- **[프롬프트 정리 및 주간보고서](./prompt-organization.md)**: AI 프롬프트를 체계적으로 기록하고 주간 진행 상황을 관리하는 자동화 워크플로우

## 🎯 워크플로우 사용 가이드

각각의 워크플로우 문서는 다음 정보를 포함합니다:

1. **목적 및 사용 시나리오**: 워크플로우를 언제, 왜 사용하는지
2. **빠른 시작**: 원 클릭으로 실행 가능한 통합 스크립트
3. **단계별 상세 가이드**: 각 단계를 개별적으로 실행하는 방법
4. **사용 팁**: 효과적인 활용을 위한 팁 및 베스트 프랙티스
5. **트러블슈팅**: 자주 발생하는 문제와 해결 방법

## 📌 빠른 참고

### 프롬프트 정리

```powershell
# 프롬프트 문서를 자동으로 생성하려면:
# 1. PowerShell을 엽니다
# 2. 프로젝트 루트 디렉토리로 이동합니다
# 3. prompt-organization.md의 통합 스크립트를 복사하여 실행합니다
```

### 주간보고서 작성

```powershell
# 주간보고서 섹션을 자동으로 생성하려면:
# 1. PowerShell을 엽니다
# 2. 프로젝트 루트 디렉토리로 이동합니다
# 3. prompt-organization.md의 주간보고서 스크립트를 복사하여 실행합니다
# 4. 클립보드에 복사된 내용을 readme.md에 붙여넣습니다
```

## 🤝 기여 방법

새로운 워크플로우를 추가하거나 기존 워크플로우를 개선하려면:

1. 이 디렉토리에 새 마크다운 파일 생성
2. 위의 구조를 따라 문서 작성
3. `README.md`의 목차에 링크 추가
4. PR을 통해 변경 사항 제출
